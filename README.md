# sudoku-puzzle-solver-csp-sa

A Python project that generates Sudoku puzzles and solves them using **Simulated Annealing** and **Constraint Satisfaction Problem (CSP)** techniques.

The project includes both **9×9** and **16×16** Sudoku versions.

## Features

* Random puzzle generation.
* Easy, Medium, and Hard difficulty levels.
* Simulated Annealing solver.
* CSP solver using MRV, LCV, forward checking, and backtracking.
* Solution validation.
* Runtime and performance measurements.

## Technologies

* Python 3
* Artificial Intelligence
* Constraint Satisfaction Problems
* Simulated Annealing

## How to Run

### 9×9 Sudoku

```bash
python sudoku.py
```

### 16×16 Sudoku

```bash
python 16-sudoku.py
```

Follow the program instructions to select a difficulty level and solver.
